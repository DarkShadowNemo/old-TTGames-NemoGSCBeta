# installation


1. download nemogscbeta_complete.zip
2. extract the zip file to a folder
3. open blender 4x
4. navigate to edit, preferences
5. install each individual addon zip using install from disk
6. enable the addons u need


# important notes

install each addon separately

only enable the parts required for your work

some parts may require other parts to be installed first

keep the original zip files as backups


# perfomance
